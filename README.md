# PaperSmart

Language: [English](README.en.md) | [中文](README.zh.md)

![PaperSmart workflow](assets/papersmart-hero.png)

PaperSmart is a reusable skill set for scientific manuscript projects. It keeps source material, references, drafts, figures, revisions, translations, and submission files in predictable places.
