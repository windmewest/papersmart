# /papersmart-new-project

Use the `PaperSmart-new-project` skill.

## Preflight

1. Confirm the workspace is already initialized.
2. Read the language profile.
3. Get the working title or topic.

## Plan

Create a new `paper_XX_slug` project with draft, reference, output, config, logs, and writing sample folders.

## Commands

Follow `PaperSmart-new-project`. Use `papersmart-new-project/scripts/new_project.py` when deterministic scaffolding is needed.

## Verification

Confirm the project folder, active project profile, and required template files.

## Summary

Report the new project path and where to place source materials.

## Next Steps

Use `/papersmart-outline` after source materials and references are placed.
