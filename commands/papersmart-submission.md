# /papersmart-submission

Use the `PaperSmart-submission` skill.

## Preflight

1. Identify the active project.
2. Read the manuscript, target journal files, style notes, reference index, figures, tables, declarations, and revision logs.
3. Check whether anonymization is required.

## Plan

Prepare the journal package without inventing author details, declarations, funding, conflicts, ethics statements, or acknowledgements.

## Commands

Follow `PaperSmart-submission`.

## Verification

Check required files, journal formatting, declarations, references, figures, tables, and anonymization.

## Summary

Report package contents, missing items, and submission checklist path.

## Next Steps

Use `/papersmart-revision` if the final package reveals manuscript issues.
