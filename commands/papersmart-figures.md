# /papersmart-figures

Use the `PaperSmart-figures` skill.

## Preflight

1. Identify the active project.
2. Read project config, data inventory, style notes, reference index, visualization plan, and relevant data or source images.
3. Define the figure's claim before creating it.

## Plan

Create manuscript-ready figures, captions, source notes, and visualization plans that support the manuscript argument.

## Commands

Follow `PaperSmart-figures`. Use source orientation unless there is explicit evidence that rotation is required.

## Verification

Check file names, captions, source notes, resolution, numbering, and manuscript citations.

## Summary

Report generated or updated figures and remaining figure risks.

## Next Steps

Use `/papersmart-draft` or `/papersmart-revision` to cite updated figures in the manuscript.
