# /papersmart-translation

Use the `PaperSmart-translation` skill.

## Preflight

1. Identify the active project.
2. Read the source manuscript and relevant table, figure, caption, and claim-source files.
3. Preserve citation numbers, figure/table numbering, TODOs, and evidence boundaries.

## Plan

Translate into polished Chinese academic prose without adding new data, citations, claims, declarations, or acknowledgements.

## Commands

Follow `PaperSmart-translation`.

## Verification

Check terminology consistency, citation preservation, captions, TODOs, and translator notes.

## Summary

Report translation path, notes path, and unresolved confirmations.

## Next Steps

Use `/papersmart-revision` if the translated manuscript needs focused edits.
