# /papersmart-outline

Use the `PaperSmart-outline` skill.

## Preflight

1. Identify the active project.
2. Read required project config, draft inventory, style notes, reference index, and relevant source files.
3. Check whether target journal constraints exist.

## Plan

Build the manuscript argument, section plan, evidence plan, and figure/table plan.

## Commands

Follow `PaperSmart-outline`. Do not draft full manuscript prose unless the user asks for drafting.

## Verification

Confirm that each major section has evidence, source traceability, and TODOs for missing inputs.

## Summary

Report the outline path and major missing evidence.

## Next Steps

Use `/papersmart-draft` when the outline and source materials are ready.
